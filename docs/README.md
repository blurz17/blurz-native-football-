# 📚 Blurz Native Football — Documentation Index

This directory holds all the historical records, architecture plans, and achievements for the project. 

## Directory Structure

* 🐞 **`/bugs/`** — Identified bugs, error logs, and reproduction steps.
* 🛠️ **`/fixes/`** — Detailed explanations of how we solved critical bugs and crashes (e.g., the gl4es Android crash).
* ✨ **`/features/`** — Records of newly implemented features and systems.
* 🏗️ **`/architecture/`** — Technical documentation on how the game engine works (e.g., the UI system, event bus, rendering).
* 📋 **`/issues/`** — Outstanding tasks, missing features, and planned refactors.
* 🚀 **`/milestones/`** — Major project achievements, version releases, and phase completions.
