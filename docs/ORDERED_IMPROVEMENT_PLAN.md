# Ordered Character Improvement Plan

This plan is based directly on **Task 5** of the project specification:
> *"5. ORDERED IMPROVEMENT PLAN: cleanup/retopo, proportions, face and hair, UV rebuild, texture bake, weight fixes, LODs. Mark which steps can be scripted and which are manual."*

| **5** | **Texture Baking & Masking** | • Generate dynamic 8-bit RGB color tint mask (Red=Kit Primary, Green=Kit Trim, Blue=Skin Tone, Black=Static).<br>• Create official referee diffuse texture map with vertical pinstripes and crest.<br>• Setup shader tint math: $\vec{C}_{\text{final}} = \vec{C}_{\text{base}} \cdot [M_R \cdot \vec{K}_1 + M_G \cdot \vec{K}_2 + M_B \cdot \vec{S} + (1 - \Sigma M)]$. | **Scripted & Painted** | [`tools/workbench/build_texture_system.py`](file:///e:/MY-PROJECTS/android%20native%20football/tools/workbench/build_texture_system.py)<br>Photoshop / GIMP / Python | ✅ **Completed** |

| **7** | **LOD Pipeline** | • Generate **LOD0 High-Fidelity** (**11,766 Triangles** / 7,651 Verts) for cutscenes and replays.<br>• Generate **LOD1 Gameplay Match** (**5,663 Triangles** / 4,106 Verts) for 22 on-pitch players.<br>• Ensure 100% UV retention and identical 34-bone skeleton across both LODs. | **Scripted** | [`tools/workbench/pipeline_step7_dual_lods.py`](file:///e:/MY-PROJECTS/android%20native%20football/tools/workbench/pipeline_step7_dual_lods.py)<br>Blender Decimate Modifier | ✅ **Completed** |
